# Практическое задание 3Б. Справочник пользователей

## Файлы
- index.html — разметка страницы
- style.css — оформление
- app.js — логика (fetch, async/await, DOM, поиск)
- README.md — этот файл

## Как запустить
1. Открыть index.html в браузере
2. Дополнительных серверов/установки не требуется — используется публичный
   тестовый API https://jsonplaceholder.typicode.com.

## Что реализовано
- Кнопка «Загрузить пользователей»: GET https://jsonplaceholder.typicode.com/users
  через fetch + async/await, проверка response.ok, вывод имени, email и города
  через DOM (createElement, textContent).

- Поиск по имени: фильтрация уже загруженного массива без нового запроса,
  регистр не важен (toLowerCase). Пустой результат — «Пользователи не найдены».

- Кнопка «Показать публикации» на карточке каждого пользователя:
  GET https://jsonplaceholder.typicode.com/posts?userId=ID, вывод заголовков
  и текстов первых трех публикаций в отдельной области.

- Состояния: «Загрузка...» при каждом запросе, блокировка кнопки
  «Загрузить пользователей» на время запроса, повторная активация в finally.

- Ошибки: response.ok + try/catch/finally; при ошибке — красное сообщение,
  кнопка снова активна для повторной попытки.

## Результаты проверки
1. «Загрузить пользователей» →появится на странице 10 карточек (имя, email, город),
   сообщение «Загружено пользователей: 10», поле поиска активируется.
2. Ввод «Leanne» → остается Leanne Graham, сообщение «Найдено: 1».
   Ввод «zzz» → «Пользователи не найдены».
3. Нажатие «Показать публикации» у пользователя → в отдельной области
   появляются 3 публикации (заголовок + текст), заголовок блока —
   «Публикации пользователя: <Имя>».
4. Проверка 404: в app.js временно заменяем USERS_URL на
   "https://jsonplaceholder.typicode.com/userz" → красное сообщение
   «Не удалось загрузить пользователей: Ошибка сервера: 404»,
   кнопка снова активна. После проверки адрес восстановлен.
